How this RTP
list works

Jaiho91 game information with daily updates in Indian Standard Time.

How are the games ranked?

The daily list shows up to 10 games, ranked by simulated RTP above 97%. Search and filters apply to today’s lineup.

When does the list change?

Every day at 12 PM IST. The list stays fixed until the next update. If you leave this tab open, the ranking updates at reset. It also catches up when you return to the tab. Keep your device clock set correctly.

What does RTP mean?

RTP stands for Return to Player. It describes a game’s theoretical return over a large number of plays. It does not predict the result of your next game or session.

How do I save a game?

Tap the bookmark on a game, then open Saved next to the search box. Bookmarks are stored in this browser. Saved games appear in the filter when they return to the daily top 10.

Are the covers the same as in the app?

The game covers are recreated artwork based on the supplied game list and screenshots. They may differ from the images shown in the app.
